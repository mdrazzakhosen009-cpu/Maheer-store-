# MAHEER STORE

Premium skincare e-commerce store built with Node.js, Express and Turso.

## Render Environment Variables
- TURSO_DATABASE_URL
- TURSO_AUTH_TOKEN
- ADMIN_PASSWORD
- GROQ_API_KEY (optional for AI)
- GROQ_MODEL (optional, default: openai/gpt-oss-120b)
- GROQ_VISION_MODEL (optional, default: qwen/qwen3.6-27b)

The admin login image is fixed at `admin/assets/login-logo.jpg` and is not exposed as a logo-change setting.
